# DGG design notes and validation records

Historical design memos, pre-flight reports, blocked-run handoffs
(*.red), and their companion Agda scratch files from the M1-M3 arc
(2026-08, PR #124). The scratch files were type-checked from the repo
root (`agda -i GTSFImp -v0 <file>`) against the tree states of their
era; they are point-in-time validation records, not live gates, and
are not part of All.agda. The live ledger is ../PLAN.md.

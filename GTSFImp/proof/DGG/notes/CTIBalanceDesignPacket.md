Status: design only. This packet does not change

The motivating obstruction and both ladders below are checked against the

## Trusted obstruction

At checkpoint C1, the second target reveal changes the current source
embedding from target `Y′` to target `X′`. In the endpoint names printed by the
focused ladder:

- before the rebase, source `X` embeds at center `Z` while target `X′` embeds
  at center `Y`;
- after the rebase, source `X` and target `X′` both embed at center `Y`;
- therefore `X ⊑ X′` is derivable after the rebase and is not derivable before
  it.

The inner lambda is not hypothetical. It is the checked `ƛ⊑ƛ²` subderivation
under the two reveal/rebase nodes of `Example12.checkpoint₁-imprecision`:

`λx. x ⊑ λx. x : (X ⇒ X) ⊑ (X′ ⇒ X′)`.

Consequently, a complete chronological `SourceRebaseStack` cannot simply be
lifted under this lambda. Its term-scope constructor would need the false
premise `X ⊑ X′` at the pre-rebase root.

## Minimal local balance index

The smallest candidate records only the endpoint pivots of locally open source
rebase frames:

```agda
record RebaseFrame (Δᴸ Δᴿ : TyCtx) : Set where
  constructor _↔_
  field
    source-pivot : TyVar Δᴸ
    target-pivot : TyVar Δᴿ

OpenFrames : TyCtx → TyCtx → Set
OpenFrames Δᴸ Δᴿ = List (RebaseFrame Δᴸ Δᴿ)
```

The proposed canonical judgment adds this one index:

```agda
_⊢²[_]_⊑_∶_ :
  (frames : OpenFrames (Δᵉ Γᴸ) (Δᵉ Γᴿ))
  → (γ : Γᴸ ⊑ᶜ Γᴿ)
  → Term (Δᵉ Γᴸ) → Term (Δᵉ Γᴿ)
  → {A : Ty (Δᵉ Γᴸ)} {B : Ty (Δᵉ Γᴿ)}
  → A ⊑ᵀ⟨ γ ⟩ B → Set
```

We write it as `frames ⊢²[ γ ] M ⊑ M′ ∶ p`. A term binder preserves
`frames`. A paired type binder maps every `(Xᴸ ↔ Xᴿ)` to
`(suc Xᴸ ↔ suc Xᴿ)`. A source-only type binder maps it to
`(suc Xᴸ ↔ Xᴿ)`. All constructors that do not change type scope pass the same
index to every recursive premise.

The index is deliberately not a world-indexed rebase proof. Such a proof
cannot survive the trusted lambda above without inventing a pre-rebase binder
relation. The local pair is exactly the information needed to enforce LIFO
nesting and can be shifted through type scope.

## Candidate rules after the proposed change

The reveal premise pushes its source/target pivot pair. The matching conceal
conclusion requires that exact pair at the top and its premise pops it. Thus
the relation itself makes crossing frames unrepresentable.

```agda
⊑reveal-rebase² : ∀
    {frames : OpenFrames (Δᵉ Γᴸ) (Δᵉ Γᴿ)}
    {γᵖ : Γᴸ ⊑ᶜ Γᴿ}
    {M M′ A B B′ Xᴸ Xᴿ Rᴿ}
    {c′ : Conv↑ (Δᵉ Γᴿ) B B′}
  → (c′⊢ : Σᵉ Γᴿ ⊢↑[ Xᴿ ⦂ Rᴿ ] c′)
  → SourceRebaseᶜ γ γᵖ Xᴸ Xᴿ
  → {p : A ⊑ᵀ⟨ γᵖ ⟩ B}
  → ((Xᴸ ↔ Xᴿ) ∷ frames) ⊢²[ γᵖ ] M ⊑ M′ ∶ p
  → (q : A ⊑ᵀ⟨ γ ⟩ B′)
  → frames ⊢²[ γ ] M ⊑ M′ ↑ c′ ∶ q

⊑conceal-rebase² : ∀
    {frames : OpenFrames (Δᵉ Γᴸ) (Δᵉ Γᴿ)}
    {γᵖ : Γᴸ ⊑ᶜ Γᴿ}
    {M M′ A B B′ Xᴸ Xᴿ Rᴿ}
    {p : A ⊑ᵀ⟨ γᵖ ⟩ B}
    {c′ : Conv↓ (Δᵉ Γᴿ) B B′}
  → (c′⊢ : Σᵉ Γᴿ ⊢↓[ Xᴿ ⦂ Rᴿ ] c′)
  → SourceRebaseᶜ γᵖ γ Xᴸ Xᴿ
  → frames ⊢²[ γᵖ ] M ⊑ M′ ∶ p
  → (q : A ⊑ᵀ⟨ γ ⟩ B′)
  → ((Xᴸ ↔ Xᴿ) ∷ frames) ⊢²[ γ ] M ⊑ M′ ↓ c′ ∶ q
```

No other reveal or conceal rule changes the balance index. In particular, the
paired rules and structural-identity rules stay in one world and therefore
pass `frames` unchanged.

```text
(((7 ↓ seal X′) ⟨ X′↦★ ⟩) ↓ seal Z′) ↓ seal Y′
```

```text
[]
  reveal Z′  → [X ↔ Z′]
```

The shift from C1 target `X′` to C12 target `Y′` is the ordinary index shift
caused by the intervening paired allocation; it is not a different beta

## Canonical relation or separate balance derivation

### Integrate the index into CTI

This changes the one canonical judgment and migrates every constructor and
consumer in place. It gives reveal/conceal nesting by construction, makes the
needed balance evidence available to `TransportSourceBind` and simulation,
and avoids any possibility that a CTI derivation and a separate balance proof
disagree. The migration cost is mechanical but broad: every constructor,
example, inversion lemma, substitution theorem, transport theorem, and
simulation interface receives the index.

### Keep CTI and add a separate indexed derivation

The alternative is a judgment such as
`Balanced² frames related`, indexed by an existing CTI derivation. Its
constructors would mirror all recursive CTI constructors and use the same push
and pop clauses above. This avoids changing CTI immediately, but permanently
creates two relations that must be threaded together. Every CTI-producing
proof must also produce the mirror derivation, and every inversion must keep
the two synchronized.

### Recommendation

If the trusted-example audit confirms the proposed push/pop trace at every
rebase checkpoint, prefer integrating `OpenFrames` into CTI. The repository is
closed-world, so an in-place migration to one canonical relation is smaller in
the long run than maintaining a wrapper relation and synchronization layer.
Do not keep an unindexed CTI compatibility alias. Before editing the live
relation, the remaining gate is to generate the same frame trace for all
trusted examples that use `⊑reveal-rebase²` or `⊑conceal-rebase²` and confirm
that each conceal pops the current top frame.
